# 首页与品牌

用户提供 `logo-source-transfer-v5/pakka-logo.svg` 和 `pakka-logo-dark.svg`，用于首页与其他品牌入口。两份文件按原始字节复制到 `src/assets/`，保留主体、灰色粒子与透明底。

首页采用 Logo、两行衬线标题 `Where all miracles begin.` 和“进入工作台”。“继续工作”直接打开原 Conversation；公开列表中的已加载、未归档对话按名称排序，最多三条。提供商与模型、设备与访问按当前注册导航显示。未登录时主按钮打开共享登录弹窗。手机保留完整长标题并将快捷入口纵向排列。

用户反馈首页位置偏高后，整体下移：桌面顶部留白按视口高度的 14% 调整，并限制在 56–160px；手机用 7%，限制在 40–64px。保留原内容间距，让标题更接近中部，同时维持对话入口的可见性。

品牌组件用于侧栏、手机页头、导航抽屉与首页。构建器按 `image/svg+xml` 登记 SVG，原始文件进入固定资产 manifest；favicon 与页面遵循个人外观及系统明暗偏好。

预期见 [WebUI state](../state/webui.md)。本轮使用类型检查、构建、原 SVG 字节比对及隔离服务浏览器路径验证；320/390px、明暗/系统主题、登录入口、对话和设置导航均已检查。固定交付与上线结果见 [首页验证](../verification/BRANDED-HOME.md)。变更属于页面布局与固定静态产物，采用影响域验证，不新增冻结 DOM/CSS 的持久测试。
