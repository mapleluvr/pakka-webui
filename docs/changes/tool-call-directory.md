# 工具调用目录与共享图标

活动段保留正文间的原始顺序、状态和非零计数。采用连续目录而不是一叠工具卡片：在路径或命令旁用 SVG 标明操作类型。没有调用声明时保留结果和实际工具名，不生成命令、差异或耗时。

展开一次调用即可一起看输入和输出。复制只复制相应预览；能定位存档的参数或输出在同一标题栏进入已有的原文阅读、分段搜索与下载。采集丢弃与预览不完整分别说明。调用 ID 和其他参数退到次级信息；消息操作仍属于其原 Entry。

codemode 的文本、图片、Console 和失败信息按实际输出呈现，脚本另行展开。只有既有解析器识别的运行记录才提供耗时；输出段、脚本源码或函数名不代表收到独立的子调用。重复错误仍可逐条展开，查看错误不执行工具。

图形在 `@pakka/webui-sdk/icons` 提供，正式 Conversation 与扩展消费同一实现；用法、图标名与可访问按钮示例见 [UI SDK](../development/UI-SDK.md#可复用的-svg-图标)。新增子路径由 SDK 导出和共享资产 import map 共同提供，不改变服务版本，也不要求插件使用新的图标库。
