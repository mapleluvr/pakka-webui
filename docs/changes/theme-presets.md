# 主题配色预设

依据用户提供的四组 RGB 与明暗规则，在外观页提供原色、浅松／艾青、乌梅／玉白、黛青／月白、霁蓝／茶白五个选项。选择即生效，保存在当前浏览器，并与字体、字号和明暗偏好共同恢复；原色继续作为默认。采用的颜色与模式语义见 [WebUI state](../state/webui.md#语音与外观)。

乌梅与黛青按模式交换底色和字色。霁蓝固定深底浅字，面板与按钮调整为相近深度，维持茶白字可读。浅松和艾青保留精确色值用于点缀与柔和光晕；白字正文采用加深的绿色衬底。固定配色暂时停用明暗选择，保留用户原偏好。主题选择卡显示双面样例，外观预览提供输入框、主次按钮和可打开的浮窗。

主题使用静态 CSS 与 Astryx 公开语义 tokens，覆盖应用主题边界和 portal 的颜色、焦点与阴影，不增加运行时 inline 样式。默认 Logo 保持源文件字节；明暗资源按实际配色选择。旧存储记录无需迁移，未知主题回到原色。

本轮采用影响域类型检查、构建和真实浏览器路径验证，不新增固定 DOM/CSS 结构的永久测试。具体候选、模式矩阵、移动布局与部署结果见 [验证记录](../verification/THEME-PRESETS.md)。
