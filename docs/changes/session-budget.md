# Session 预算：默认不限制

此前界面、协议和运行时只接受正数；仅改变表单会使显示和真实接纳行为不一致。预算页从实际存储回显三项上限，0 可编辑和保存，当前预算及历史将 0 显示为“不限制”。已有有限值、计数、权限、冲突和原请求回执语义不变。现有组件没有新增 DOM 快照测试；协议边界与持久效果由 Pakka 维护，完整归档经安装态浏览器检查。

前端通过[两份固定包](../../vendor/README.md)消费 services 5 / workbench 3，不复制 decoder。资产 schema 和扩展协议不变，旧前端不能只替换静态文件接入新后端。Pakka 的配对记录维护归档和 manifest 的预期摘要。
