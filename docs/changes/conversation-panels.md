# 本页搜索与输入回执浮窗

本页搜索原先占用阅读列；「我的输入」原先用模态对话框遮住整页，模式、状态与原始原因排成一行。现在两者在同一 Conversation 内共享非模态浮层，保留正文、原文和输入框的独立操作。浮窗入口和恢复、关闭按钮分别有可访问名称；位置只属于本次打开的视图，不写入偏好或对话记录。桌面可拖动标题或用方向键微调，手机按可见窗口贴边显示。窄屏只显示最前一窗，切换入口时保留另一窗的筛选、列表与展开状态；若正在筛选，搜索入口显示「筛选中」。关闭最前一窗可回到上一窗，桌面继续允许两窗并列。

搜索仍按当前页预览段匹配，不请求其他历史或截断的正文。输入清单分开显示模式、回执状态、可展开的消息预览与原请求身份。折叠预览最多取 100 个 Unicode 码点、三个原始文本行，展开显示本次读取的完整预览。服务标记截断的预览即使展开也不是原文。输入回执 `reason` 为可选开放字符串：只解释已知原始值，其他值原样显示，原始原因可在回执详情核对。

刷新与分页只读原清单。撤回仍针对所选回执，停止仍在输入面板原位；待确认控制保留原请求号，关闭浮窗不确认、取消或重放操作。采用的行为见 [WebUI state](../state/webui.md#布局与界面元素)。类型检查与构建不代替浏览器操作或服务回执核对。
