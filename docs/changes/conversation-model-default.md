# 从对话选择器设置个人默认模型

对话模型按钮和 `/model` 共用一个选择器。搜索、翻页和移动高亮不保存；点按模型、在搜索框按 Enter、输入完整 `/model provider/id` 仍只切换当前对话。高亮、当前对话模型与个人默认分别标识。

在该选择器中，可以使用「设为我的新对话默认模型」、Ctrl+Enter（macOS ⌘+Enter），或在触屏上按住具体模型约 550ms 再松手。可见操作的目标也能直接选择。移动、滚动、多指、取消或更换列表均不完成长按；长按后的兼容 click 不执行当前对话换模。设置个人默认后仍停留在选择器，不清空输入框。若本人之前选定了新模型不支持的 Thinking 级别，需要另行确认改用模型默认；没有显式级别或兼容时直接保存。

个人设置与对话配置独立授权。选择器使用设置页同一 Person 原请求槽、期望版本与回执查询。冲突后读取现在的默认，由用户决定是否继续；未确认请求不重发。原回执只说明原请求，当前标记以重新读取的记录为准。个人设置页「恢复跟随实例」将模型与 Thinking 同时改为空草稿；保存后仅影响本人新建、未指定模型的 default profile 对话，不更改实例配置或已有对话。
