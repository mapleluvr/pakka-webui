# 悬浮输入与阅读宽度

用户依据两张输入面板参考图及停止图标确认试作后，采用悬浮面板与顶部操作的布局。通用 `.surface` 阴影原先覆盖输入区的无阴影声明，形成矩形投影；输入外层改为透明且无阴影，圆角面板独立承接底色、边框、投影和焦点。

空白和短句保持紧凑，长文上展并支持大窗口编辑。运行时原位停止，隐藏听写；菜单保留 Steering／Follow-up 投递。停止继续核对原控制请求，服务端活动结束后恢复发送。我的输入使用独立浮层，搜索、刷新、设置及会话标识移到页顶。模型选择与个人默认、配置、听写插入、slash 命令、待确认与恢复共用既有功能路径。

正文宽度支持四档、连续滑杆、恢复默认与浏览器保存；手机保持自身宽度，输入面板独立。文字换行判定使用紧凑布局的固定测量宽度，避免面板展开后又因宽度变化而收起。

采用的完整行为见 [state](../state/webui.md#布局与界面元素)，固定归档与验证范围见[验收](../verification/FLOATING-COMPOSER.md)。本轮选用影响域类型检查、标准归档构建、实际安装与隔离服务浏览器场景；不新增固定私有 DOM 的持久测试。
