# Conversation 笔记与置顶

原人类协作视图中的单份共享文本不能独立编辑或指向模型消息。顶部现有搜索、我的输入旁增加「笔记与置顶」纯图标；其内部由笔记清单、编辑器、置顶清单与原文预览组成，不借用聊天数据。协作模式仍有自己的「人类聊天」入口，个人模式没有聊天入口或展开开关。

笔记按正文/标题搜索、分页。可从稳定消息或工具结果菜单置顶，也可用当前预览摘录新建草稿；实时临时结果不能置顶。拒绝与未知结果分开，Session 存储中的待确认原请求仅供核对。删除确认点名笔记及关联置顶；不会删除原消息。

应用通过 [公开归档](../../vendor/README.md)消费 Pakka 契约，不导入另一棵工作树。配对要求为 services 7 / workbench 3 / extensions 3。SDK 公开 `pin`、`link` 图标，不拥有笔记存储。变更保留既有阅读宽度、搜索浮窗、模型草稿与虚拟化；本轮未增加固定 DOM 或私有组件测试。
