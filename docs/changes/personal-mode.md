# 个人模式与设备

用户批准同一身份多端接续使用的设计。采用状态见 [WebUI state](../state/webui.md#个人模式与设备)，宿主能力属于 Pakka，前端通过 services 6 / workbench 3 的公开 protocol/client 消费。

「设备与访问」提供个人/协作模式切换、本人设备清单与单独退出。个人模式提供「连接我的设备」，默认一小时的一次性链接与二维码；有效期在链接选项中调整。已有身份登录可省略姓名。角色和资源分配退出个人模式日常界面，人类 driver 与在场隐藏；笔记与置顶仍可打开，聊天可按需展开。

「新对话默认模型」说明跨设备的新对话选择；实际共享沿原 Person 持久服务完成。预算显示「备注（可选）」，修改记录以时间和额度变化为摘要，完整身份与请求记录按需展开。模式/设备修改的未知结果保留原请求，并说明具体修改对象。
