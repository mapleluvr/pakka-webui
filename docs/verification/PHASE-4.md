# 阶段 4：独立应用候选与退出边界

## 当前结论

2026-11-19 的候选在 Node 24 仓库外 consumer 中完成固定安装、生产资产装载、真实登录、普通输入、确认期间的新草稿保留、刷新回执和撤权清理。新工作台的 PC / 390px 阅读与输入已经直接检查。

阶段 4 退出仍受阻：扩大回归选取 334 个文件，完成 333 个文件记录；短目录复验解决两处维护失败后，仍有 13 个失败文件，另一个旧样式浏览器检查未完成。工作分支保存候选，默认产品、合并与发布保持各自门禁。

前端消费 services 4 / workbench 2 / extensions 3、资产 schema 2。阶段 2/3 的 services 3 固定组合继续由各自验证记录承接。

| 扩展与插件     | Backend / Agent / WebUI / Client 独立控制；RSI、MAS、文件/Git、审批、服务器浏览器、Memory、定时输入、Webhook 由所属包提供页面 |

上述业务路径来自分批真实页面、原生服务与 HTTP 检查。最终安装轮选择登录和普通输入作为代表性端到端路径，生产 loader 同时校验所有 713 个资产；该轮没有逐个重跑全部插件交互。

界面形成与较长原文、阅读位置、三种尺寸、原请求恢复的详细结果见[工作台界面](WORKBENCH-INTERFACE.md)。后端与插件的权限、效果及回执范围见[阶段 4 后端记录](https://github.com/mapleluvr/pakka/blob/pakka/independent-webui-seams/docs/verification/INDEPENDENT-WEBUI-PHASE-4.md)。

## 安装版端到端结果

1. 凭据链接打开一个可见登录 modal，按钮命中实际 modal 并完成登录。手机导航与登录同时打开时为两种 modal，其中登录实例始终只有一个；取消后回焦到可见登录入口。
2. 最新安装轮先后提交三笔独立输入：前两笔留住已接纳响应、继续编辑新草稿、再释放响应，草稿保留；第三笔在 390px 正常发送，确认后仍为原正文的输入框清空。每笔经安装版 Pakka → 原生 Runtime → 本地确定性 Provider，各一次真实请求，只包含对应提交正文。
3. 刷新后重新读取同一对话与完成回执，Provider 总计数仍为三次。
4. 打开配置窗后撤销当前 Person，阅读正文、输入框及 modal 全部清除。手机登录入口仍可打开/取消，回焦正确。
5. 草稿保护最终轮服务正常关闭，服务 errors 为 0、Provider 请求为 3；前两轮固定登录/工具栏验收各自为 1。浏览器任务空间已结束。
6. 本轮浏览器监听覆盖 error、unhandled rejection 与 CSP（Content Security Policy，内容安全策略），完整通过轮记录为 0。首个草稿复验缺少监听，只保留草稿和请求计数的结论；第二笔独立输入、手机发送、刷新及撤权完整补验。一次未设置 viewport 的观察在 1920px 被拒，原记录保留；稳定手机截图等待实际过渡结束。

## 检查与仍需接续的部分

两仓类型检查和构建通过，最终前端重新打包通过。局部主动 LSP（Language Server Protocol，语言服务器协议）检查三个文件未报诊断，其中两个确认 clean，一个 push-only 服务器未确认；本记录保留该覆盖限制。

扩大回归保留 13 个失败文件：composition、文件、MAS、Memory 恢复、通知和旧排版等仍调用旧默认页面；`mas-stylesheet-browser` 等待未发出的样式请求，已取消并清理。真实新页面与 HTTP 的分项证据单独保存。该集合尚未获得退出许可，下一步须核对独特契约覆盖、旧默认入口与检查的接续方式。

维护两文件的短目录复验共 13 项通过，继续使用生产 ACL（Access Control List，访问控制列表）检查。原 Windows 长路径失败保留，权限规则保持原值。

- 真实录音：用户因本机无录音设备授权跳过；识别连通性和质量仍未验证，事件样例仅证明草稿行为。
- worker 更新：此前固定编译变体 A → B → A 清除 Pakka 通知、保留隔离非 Pakka 项，旧 worker redundant，旧授权读取被取消；仍向旧 worker 送达正文的分支未覆盖。
- 推送部署：隔离原生轮只许可实际的 `https://jmt17.google.com` origin；部署者须批准自身端点，服务发送回执 unknown 与系统实际显示分别保留。
- 默认入口切换属于阶段 5；Provider `/login` 沿 roadmap 延期。
