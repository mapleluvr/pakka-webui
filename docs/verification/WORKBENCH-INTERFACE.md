# 工作台界面与输入恢复核对

本记录覆盖阶段 4 的主界面代码试稿。前端消费固定 services 4 / workbench 2 / extensions 3；使用实际 Pakka、原生 Runtime、公开客户端与隔离本地 Provider。最终固定归档、默认产品切换与阶段退出分别核对。

## 使用路径

- PC 侧栏与手机导航抽屉集中放置功能、已打开页面及设置。Conversation 标题位于页面首部，完整原引用收进次级详情。
- 历史使用独立阅读区，输入固定于下部；本人输入清单与阅读导航位于两者之间。模型、Thinking、目录/preset 与听写共用紧凑工具栏。
- 消息 header 按 User/Assistant 角色提供复制、原文与消息操作；分叉使用原 Entry。原文打开为独立阅读模式，搜索与返回入口可达。
- 同一视图选取一条原文，搜索和行位置按各条原内容身份分别保留。固定阅读导航提供返回预览，关闭后回焦原入口。
- 明确发送后退出原文并跟随新回复；手动滚动、搜索或正文操作暂停跟随。同一读取范围的历史刷新保留阅读实例，配置与旧请求查询保持自己的阅读位置。
- 未确认的普通输入保留完整原 target/text/mode/requestId。重新装载时从原记录初始化正文和 mode，详情显示原消息与请求号；确认旧请求时保留后来另写的草稿。

## 固定制品：确认响应期间的草稿

最终差异核对发现正常发送的成功回调会直接清空输入框。对安装版留住一次已接纳的真实响应、继续编辑、再释放响应：原消息产生一次 Provider 请求，新草稿随确认被清空。修正为比对该次提交正文后清理；原请求与输入服务保持原样。

重打并安装的固定前端为 `c783d4d22fd98d71394a8c611b19acad0df6c18af0f323ca13f075c92a31abfc`。新隔离轮两次留住确认响应后，新草稿均保留；每次实际请求只含对应原消息。第三笔 390px 正常发送没有继续编辑，确认后原稿清空。工具栏四入口同处 44px 一行，刷新后完成回执与总请求数 3 保持一致；配置窗打开期间撤权清除正文、Composer 和 modal，手机登录取消回焦通过。服务 errors 为 0，服务与 Ego space 9 均正常结束。

首个修正后探针在监听检查处失败，finally 已释放那一次原响应；随后只读确认草稿保留，未重发。该轮没有脚本/CSP clean 结论。第二笔独立输入在同次调用安装完整监听、刷新并验证，error / unhandledrejection / CSP 数组为空；390px、刷新与撤权也在完整监听下核对。一个空输入等待条件误读 Astryx 的 native disabled 属性、首个隔离启动缺少显式 transport 条件，均保留为探针前置失败。复现和复验使用临时真实页面探针，沿本阶段低固化要求保留永久服务契约回归。

记录位于最终 consumer 的 `pending-draft-check-02` / `pending-draft-check-03` 及 `docs/.temp/phase-4/ego-pending-draft-*`；固定组合和完整证据包见[阶段 4 核对](PHASE-4.md)。

## 修正与验证限制

- 同一历史刷新曾重建阅读区并重放发送标记；修正为保留同一读取范围的实例后复验。
- 原文初稿读回后搜索离开可视区，sticky header 位于虚拟位移容器底部；改为消息内原文模式、定位搜索控件、固定返回导航与可见行尺寸补偿。矮窗口仍将搜索按钮留在可视区外，搜索框和按钮合为一行后完整复验。
- 原文返回的首次焦点观察早于 requestAnimationFrame；后续按原入口实际获得焦点判断通过，原失败保留。
- 普通输入初稿刷新后只显示 requestId，原正文虽存储却没有呈现；修正初始化与原消息详情后，沿原来的丢响应样例查询，保留一次写入和一次查询。
- 若干 probe 误读内部状态节点、使用了非 DOM 的 `:has-text`、把自定义 Selector 当成原生 select、沿用了上轮视口，或缺少刷新后的错误监听。这些轮次保留观察与失败，整体验收依据为后续完整复验。
- design-companion 的候选用于推敲阅读/输入分区与紧凑工具栏；最终实现消费 Astryx、repo-native SVG/CSS 与真实正文。候选生成和代码行为各自记录。
- 2026-11-19 用户明确说明本机无录音设备，并授权跳过真实录音检查。原生 SpeechRecognition 构造器与安全上下文已只读核对，曾触发一次听写并交还权限选择；录音、语音服务连通性与识别质量保留未验证。现有受控识别事件验证草稿、取消与晚到事件的生命周期。
- 新布局另在零模型输入样例中打开配置窗口后撤权，正文、配置窗口、Composer 与听写控件均移除，旧登录返回 401；原失败与其他轮次的迟到读取证据各自保留。最终固定候选已在源码树外完成代表性登录、输入、刷新和撤权核对；完整阶段仍受扩大回归失败阻塞。
