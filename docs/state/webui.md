# WebUI 产品与架构边界

本文维护本仓采用的预期；当前实现进度见[工作入口](../OVERVIEW.md)，采用依据见[初始化记录](../changes/repository-bootstrap.md)。

## 产品与交付

Pakka WebUI 是采用 React 19、TypeScript/TSX 与 Astryx 的独立浏览器应用。前端通过版本化的公开协议与客户端连接受支持的 Pakka，能够独立安装、开发和构建。默认 `pakka` 产品提供选定版本和内容身份的前端制品。

服务面使用 `/pakka-webui` 命名空间，由 Pakka 接入层消费。首版独立开发通过同源代理联调，维持 Host/Origin、Cookie/CSRF 和明确的代理边界。服务 API、UI SDK/renderer、资产格式与内容身份各自核对兼容性。固定制品的 `inlineStyleHashes` 只声明经核对且绑定依赖版本的静态样式文本；HTTP 以精确 SHA-256 许可保持 CSP，其他 inline 样式继续拒绝。

应用通过标准 npm 静态归档交付，SDK 归档保持独立。完整归档包含 manifest 声明资产、上游许可和无运行依赖的私有 npm 元数据；现有交付不覆盖，元数据路径不与资产冲突。消费方从可信配对记录取得预期归档和 manifest 摘要，在 Session 打开前核对格式、协议与实际字节。切换固定前端遵循正常停止和原 Session 重开流程，UI 回退不回滚数据库或删除待核对操作。

## 职责与依赖

源码按实际实现需要形成以下职责目录，目录不等于独立 package：

| 职责                      | 拥有的内容                                                     |
| ------------------------- | -------------------------------------------------------------- |
| `src/app/`                | 根装配、壳层、路由、主题和连接依赖注入                         |
| `src/host/`               | 通用贡献、容器、资源视图导航、模块/版本与界面实例生命周期      |
| `src/integrations/pakka/` | 认证与连接、公开客户端、服务绑定、资源/模型 DTO 和资产来源适配 |
| `src/features/`           | Conversation、Session、设置和 Pakka 人类身份等功能界面         |
| `src/ui/`                 | 共享主题、语义 tokens 与有真实复用需要的 UI 组合               |
| `src/sdk/`                | 纯浏览器公共 UI 声明和消费入口                                 |

host 消费显式注入的贡献、解析器和能力；Pakka URL 与服务实现知识属于接入层。功能和业务插件管理自身草稿、数据适配及操作结果；执行、授权、持久化和业务账本由后端所有者维护。

## 布局与界面元素

首页以原始明暗 SVG Logo 与 `Where all miracles begin.` 为品牌中心，提供进入工作台、打开已有对话及当前身份可用的设置入口。“继续工作”最多展示三条未归档的已加载对话，按名称排序；空列表引导打开或创建对话。首页读取不创建 Session、不提交输入。未登录时使用共享登录弹窗。侧栏、手机页头与导航抽屉、favicon 使用同源品牌物料，随个人外观或系统明暗模式切换。

产品导航提供 Conversation、设置及已装配插件的实际功能。组件实验室演示页及其入口已退出默认应用；共享通知、Dialog 与插件 SDK 继续由正式功能消费。

工作台在 PC 使用侧栏，在窄屏使用导航抽屉，集中提供功能、已打开页面与设置分类。Conversation 标题为主要定位，完整原引用位于次级详情。顶部承接阅读宽度、搜索、刷新、我的输入、对话设置与会话标识；我的输入以浮层显示，保留正文阅读空间。下部悬浮圆角面板容纳草稿、模型、Thinking、听写和主操作；空白与短句保持紧凑，多行向上展开，并可打开大编辑窗。关闭编辑窗保留草稿。外层透明容器不绘制阴影，阴影跟随面板圆角。

本页搜索和「我的输入」是可同时打开的非模态浮窗，不锁定正文滚动或输入。桌面从标题拖动或用方向键移动，分别保留本次视图位置，可恢复到对话标题下方；窗口或内容变化时保持控件可见。窄至 640px 时仅显示当前操作的贴边面板，另一面板保留打开状态但不可交互；点按另一入口即可切换，关闭当前面板后可见先前打开的面板。内容在面板内滚动，不修改桌面坐标。Escape 仅从所属浮窗或其入口关闭并回焦，不接管正文的按键；离开所属对话不显示其浮窗。

搜索聚焦关键词，显示匹配段数及本页预览范围；入口标明「筛选中」。切换浮窗保留筛选，关闭搜索才退出筛选，不改变消息草稿。「我的输入」按记录区分模式与有文字的状态，长预览可展开，截断标记独立于展开状态。原因沿服务值说明，原请求、回执身份和原始原因按需查看。刷新属清单读取，分页不虚构总数；撤回与待核对控制仍沿原操作处理，不因浮窗关闭而清除。

运行时主操作原位显示停止图标，听写入口收起；停止沿原控制请求核对，以当前实时活动决定何时恢复发送。Steering／Follow-up 可在「＋」菜单显式投递草稿；普通 Enter 不在运行时自动停止或另发普通消息。模式选择保留草稿和阅读位置，配置、输入与控制的待核对状态继续阻止重复操作。

阅读宽度提供 640／820／1040px／全宽与 560–1440px 滑杆，默认 820px；桌面偏好保存在当前浏览器，窗口变窄时正文自动收窄。手机按可用屏幕宽度排版，不修改桌面偏好。正文宽度与输入面板宽度独立。PC 侧栏保留拖动、键盘微调与双击恢复；输入面板按草稿自动调高。个人文件夹列表每行展示一个名称，管理菜单分别打开重命名、删除确认。输入焦点由圆角面板承接。

消息 header 按 User/Assistant 角色提供复制、原文和消息操作，分叉定位原 Entry。同一视图选取一条原文，各条内容的查询与阅读位置独立保留；固定阅读导航提供返回预览，关闭后回焦原入口。明确发送后退出原文并接续新回复，手动滚动、搜索或正文操作暂停跟随；同一读取范围刷新保留阅读实例，配置和原请求查询保留当前阅读位置。

操作反馈经同一 `UiContext.notice` 通道短暂显示。桌面保留最近三条，窄屏在导航下方仅保留最新一条；同一实例内可互换的提示计数、续时，不同动作或目标保持独立。停留指针、聚焦、触划或页面隐藏期间暂停；可关闭或在窄屏上划移除。关闭提示不改变任何持久操作，不触发重试。实例关闭、publication 替换及身份切换清理所属反馈；瞬时命令正常返回不使其刚发布的提示消失。

登录状态与登录弹窗由壳层的一份控制状态管理。桌面侧栏与手机导航提供同一登录操作的入口，原生登录弹窗在共享主题下装载一个实例，保持当前可见入口的输入与回焦。

界面基于 React 19 + Astryx，共享主题、排版、间距和浮层规则。布局使用 CSS，控件优先组合 Astryx 公开组件；原生 HTML/SVG 与自定义组合按实际用途发展。

## 插件与共享 UI

- 纯 UI、Client、Backend、Agent facets 按实际需要组合；默认和第三方插件使用相同公开能力。RSI、MAS、Memo 的页面、控制与管线由各自插件维护。
- 纯 UI 插件无需工作 Session；打开或关闭不产生模型请求。只消费 Agent/headless 入口时，导入图保持与浏览器 runtime 和 UI 启动分离。
- 插件可以提供导航、page、sheet/panel、设置与完整自定义 React 内容，并直接使用 Astryx 的公开组件、parts、hooks、props 和类型。
- 宿主与插件共享 React/ReactDOM/JSX、Astryx 及所需 StyleX runtime、主题和浮层环境。普通 HTML、局部 CSS/SVG、自定义组件与有实际用途的局部主题可组合。
- `@pakka/webui-sdk/icons` 提供应用和扩展可直接复用的装饰性 SVG；业务含义、交互与可访问名称留给使用方，图标不引入宿主服务。
- 贡献声明、服务调用、命名空间命令和有限观察走公开接口。服务绑定承担 actor/resource 授权；界面容器承担打开、关闭、焦点、错误和清理。
- Conversation 输入按当前资源发现精确 slash/namespace 命令；Backend action 校验 JSON 参数、声明的作用域与 effect。命令发现失败保留疑似命令参数，普通路径文本仍可发送。write/model 命令的原请求在发送前保存，App 记录按来源/Person 共享，Conversation 记录按原 Session/Conversation 隔离；丢响应只查询原回执，unknown 保留。read 命令不产生持久回执，失败可重新读取。
- 每个 facet 具有独立的 version、generation 和 phase；服务调用、资产和控制按对应 facet 身份接线。WebUI publication 拥有其实例集合；Backend/Client/Agent 的状态变化各自处理。设置页逐项保留原请求，历史控制回执与重新读取的当前状态分开显示；unknown 或未找到结果不释放新控制。控制后的宿主同步须读取控制之后的发现结果，完成前核对所属实例清理，不能复用控制前已发出的读取。
- 实例绑定插件身份、版本/generation、资源与 open-instance。替换时清理所属订阅、监听、计时器与可中止读取，旧实例的结果不能进入新实例。清理失败保留并报告同一次结果；已接纳工作由所属服务接续。

## 资源与持久效果

插件持有稳定资源引用并注册自己的资源视图。Pakka 接入层将 Session/Conversation 引用交给受控来源解析，进入另一已知且获准访问 Session 的原 Conversation，读取实际历史。目标插件页面的地址包含原 Session/Conversation；直接刷新时重新解析与授权，页面资源必须与服务绑定相符。单独恢复的装载作用域在最后实例显式关闭时释放；publication 替换按其自己的生命周期重新装载。

文件/Git 页面由其插件提供，展示获准根目录、有限目录列表、文本/图片、精确导出、编辑/上传、Git 差异、分支和受控工作树。文件写入核对原 hash，冲突保留草稿；未确认写入按浏览器原请求找到宿主 operation，再按 operation ID 核对文件服务回执。移除工作树以明确选择控制未提交内容处理，浮层随所属页面可见性开合，关闭后返回原入口或可用容器。

审批页面由插件提供，读取原工具调用的参数、等待截止与当前执行状态；有管理权限者对仍在等待的调用作出一次允许或拒绝。每条原决定在发送前保留，响应未知时通过扩展原请求查询恢复，决定回执与工具当前状态独立显示。页面关闭停止观察，原调用的期限与执行由服务管理；服务重开后的未确认调用以 unknown 呈现。

服务器浏览器由插件提供获准站点内的文字、截图、导航、点击和填入入口。动作回执与当前页面状态分别呈现；浏览器原请求先定位 extension operation，再按 operation ID 核对服务回执，内层 unknown 保持待核对。暂停或关闭界面停止观察，受管浏览器由服务维护；服务重开清理原页面与临时 profile，历史动作仍按持久回执读取。

Memory 插件按项目与当前 Session 全局作用域展示已批准内容和待批准建议。普通成员及 Agent 的修改由具有审批权限者批准后进入模型上下文；只读成员读取已批准内容。编辑携带原版本，冲突保留草稿；清单重新分类、分页与刷新不覆盖正在编辑的内容。原请求在发送前保存，恢复按 extension operation → Memory 回执核对；原操作结果与当前内容分别显示。暂停控制当前 Session 的记忆上下文注入，页面关闭停止读取并释放资源。

当前有权的成员可用稳定对话身份找回配置变更前的计划并取消。计划创建者可按次核对自己的输入与执行结果。每次投递使用登记时的原运行绑定。

定时输入插件按当前获准 Conversation 提供一次或有限重复计划，显示登记、投递次数、输入回执与原生任务状态。登记与逐计划取消在发送前保留各自完整原请求，响应不明只查询原回执；当前清单变化保持与未知原请求分离。持久取消标记确认取消意图，任务停止由原生终态单独说明，已投递输入继续执行。关闭或替换页面结束读取与实例，计划继续由服务管理。

Webhook 插件按获准 Conversation 管理 GitHub 签名端点或其他服务的密钥地址，提供登记、受权读取连接设置、轮换、移除与有限接纳记录。完整原请求在发送前保存，恢复按 extension operation → Hook 回执核对；原接纳结果与当前模型工作分别显示。清单、管理与回执按稳定 Session/Conversation 和当前所需权限定位，外部投递核对端点原完整运行绑定；配置换绑后的端点以失效显示并保留清理入口。私密设置只在所属可见面板保存，隐藏、版本变化、换绑、替换、关闭或撤权结束其读取与值的生命周期。变更确认区聚焦时滚入可视范围，返回时回到原入口。

人类协作面板按获准 Session/Conversation 读取聊天、聊天置顶/reaction、短期在场状态和当前 driver。聊天/reaction 允许只读成员参与，聊天置顶与 driver 操作按服务返回的相应授权提供；模型输入另经原生 driver/期限准入。各类修改在发送前保留完整原请求，响应未知按原请求查询，历史回执与当前状态独立显示，冲突保留草稿。暂停/关闭结束所属读取与在场心跳，晚到响应留在已结束的生命周期之外。提及列表按已授权的参与者显示；人类聊天作者使用服务身份，模型历史使用 user/assistant 消息角色。

通知设置分别呈现个人偏好、获准 Conversation 的设备登记和本浏览器原生能力。只读成员也能修改自己的偏好；停用设备解除它全部已登记资源，本地推送订阅由独立动作移除。修改在发送前保留完整原请求，历史回执与当前设置分开读取；暂停或关闭界面结束设置读取，后台投递由服务继续管理。

通知 worker 接收事件/设备身份，再通过同源受权读取取得内容；点击时重新授权并打开原 Conversation。浏览器权限由用户选择，远端登记与推送使用部署者许可的精确 HTTPS origin。worker 的公共地址为 `/pakka-webui/service-worker.js`，对应固定应用资产 `notification-worker.js` 和根 scope 许可。服务发送回执、浏览器显示调用与系统实际显示各自核对；身份变化与所属生命周期结束时清理自己的显示内容和读取。

持久身份与当前运行绑定分别核对。已加载、未加载、不可得、无权和身份不符有明确状态；原 owner 保持 storage/writer 所有权，浏览只读取原对象。有限分页、搜索及按引用读取保留服务的完整内容契约。

正文按有界历史页呈现 Markdown、代码和按需图片。两段正文之间按原序将连续的工具调用和 Thinking 合成一个默认折叠的活动段；Commentary、用户消息、来源及已知任务切换均划分边界。摘要按可查看的活动计数，只列非零项，例如 `Done (1 thought)` 和 `Done (2 tool calls)`；空白 Thinking 只在原文引用仍可读到未展示内容时提供入口。实时思考可单独提示正在进行。单次调用用同一面板分隔命令（或输入）与各段输出；复制预览与原文搜索属于对应块的标题栏，调用身份与其他参数按需查看。Running 的当前动作显示最近报告的错误短句；完成后摘要只列工具调用、Thinking、工具错误和模型错误的非零计数，右括号外用红色 `Needs attention!` 标记。生成失败或中止保留 Failed 或 Stopped 状态。紧邻活动的模型错误归入该段；单独的错误以「回复失败」卡片显示，已知原因有具体说明，其他错误显示可读摘要。同一来源内相邻的同类错误可以折叠为 ×N，展开保留逐条原始记录、原文入口及操作。次数来自当前窗口可见的错误记录。原始技术详情按需展开，已生成的正文保持原位；阅读、复制或搜索错误记录不会重试。展开活动段后可逐次查看调用和 Thinking；参数、活动输出、结果按原 Session、来源 Conversation 与调用 ID 归位，搜索覆盖已载入的折叠预览。历史窗口与长原文使用虚拟列表；折叠或离开可见区释放正文和可取消读取，视图保留展开状态、原文段、搜索游标与阅读行锚点。原生采集的截断说明随保存内容显示。

活动目录以 SVG 辨认工具，以命令、脚本首行或目标路径辨认操作；没有可用字段时显示工具名。状态和已知耗时是次要信息，不从观察时间推算。Thinking 只摘取可读预览。codemode 保持一次调用：先呈现收到的文本、Console、图片或错误，脚本按需展开；脚本内容不用于推断内部执行树。实时状态更新不主动收起读者已展开的调用。窄屏减少缩进，长命令和输出在内容区滚动。

当前页搜索覆盖已载入预览；单条原文搜索沿固定内容身份逐段读取，明确显示存档范围。每段最多 64 KiB，搜索保留解码字符游标与跨段重叠；存档字节坐标与解码后的字符/字节数分别使用。完整复制上限为 1 MiB，图片编码展开上限为 8 MiB；下载由服务分段输出全部已存内容，每段核对原身份、内容版本与当前权限。HTML 跳过渲染，外部图片以主动链接提供，图片 Blob 与正文随界面清理释放。

工作台按个人操作和目标说明创建、重命名、删除、移动与排序。未收到回执时在操作处保留独立的查询入口。输入的「已收到」确认投递。仅在本人回执唯一关联原 Entry、该输入已纳入运行且当前实时观察为忙时，对应消息才显示 SVG 转环与「处理中」；减少动态效果时保留静态图文。本人已答复的消息只显示「你」，完整状态在「我的输入」可查。阅读栏的「刷新输入状态」只重新读取输入清单，「到本页最新消息」跟随本页消息。会话标识展开与历史刷新共用阅读操作的字号、触控尺寸及 SVG 图标；没有 Entry 的输入仍在「我的输入」按回执查看，不按相同文本猜测关联。正常实时连接不显示常驻状态，重连、历史阅读和不可用等情况仍在对话内说明。

工作台按已加载对话的标题搜索。高级定位接收原 Session 与 Conversation ID 并重新授权。普通输入使用发送消息、调整当前工作、本轮结束后执行三种操作。其他设备换模后仍能核对完整原请求并显示其执行结果。

持久操作通过原请求和所属服务回执确认。界面关闭、等待取消和 UI callback 结束只改变各自的界面/等待状态；unknown 效果保持待核对，不能换请求身份重放。浏览器请求、宿主 operation 和内层服务 receipt 的身份按公开契约对应。同一来源、Person 和操作作用域的待核对记录使用跨服务重开稳定的身份，发送前同步保留；已有原请求时阻止覆盖，确认或拒绝只清除对应 requestId，损坏记录保持待核对。普通输入重新装载时从该记录初始化正文和 mode，详情呈现原消息及请求号。发送或核对得到确认后，仅当输入框仍是该次提交正文时清空；等待期间后来另写的草稿保持原样。

## 语音与外观

浏览器提供安全的 SpeechRecognition 时，听写先呈现已确认和正在识别的文字，结束后由人类插入当前选区，再通过普通输入显式发送。听写期间的手动编辑保持原样；取消、隐藏、换目标或连接结束清理所属识别实例，旧实例的结果与结束事件只作用于该实例。权限、录音设备和语音服务由浏览器管理，界面显示其实际能力和失败结果。

主题配色、明暗模式、阅读字体与字号保存在当前浏览器，应用于页面、插件与浮层。原色为默认主题；乌梅／玉白（#4e2a3a／#e9e4d5）和黛青／月白（#243836／#e7ece8）在深色下前色作底、后色作字，浅色反转。浅松／艾青（#ffc44f／#5ecd8c）以双色点缀、加深的绿色衬底和白字保持固定配色；霁蓝／茶白（#2f5d8a／#fff4e3）固定为霁蓝底、茶白字。固定配色保留明暗偏好，切回其他主题后继续生效；跟随系统读取当前系统偏好。按钮、表单、浮层、焦点与阴影使用同组语义色，品牌明暗资源跟随实际页面配色。旧外观记录缺少主题时沿用原色，保持原字体与字号。阅读字体通过 Astryx 的公开 body token 接入，代码使用等宽字体。存储不可用时，更改仅在当前页面生效。

## 模型访问与配置

| 对象                     | 作用域与操作                                                    |
| ------------------------ | --------------------------------------------------------------- |
| 当前模型 / Thinking      | 当前 Conversation，按其配置权限提交                             |
| 人类默认选择             | 当前 Person，后端跨设备保存，用作其新建 Conversation 的缺省选择 |
| 提供商 / 端点 / 模型定义 | Pakka 实例，由具备配置权限者管理                                |

Conversation 输入框中的 `/model` 打开与模型按钮相同的搜索选择器；`/model openai/gpt-4o` 这类完整 provider/model 身份直接精确选择，失败时明确报告。点按或普通 Enter 只更新当前 Conversation。选择器另提供「设为我的新对话默认模型」、Ctrl+Enter（macOS ⌘+Enter）及触屏稳定长按后松手，均按高亮模型的完整身份操作，不提交输入草稿。新目标兼容时保留个人 Thinking；只有显式级别不兼容时才需确认回到模型默认。个人默认与对话配置分别授权、保存和核对；个人设置页和选择器共用本人原请求槽，历史回执不取代对当前默认的读取。个人设置页「恢复跟随实例」先改草稿，保存后才对本人未显式选模型的新建 default profile 对话生效。已有对话和工作流的显式选择不变。

`/thinking` 与输入区 Thinking 按钮打开同一锚定菜单，按模型支持的顺序逐行列出级别。勾选标明配置读取到的当前级别；未显式设置时仅提示「模型默认」。方向键、Home／End、Escape 和点按外部均不提交；选择级别或输入 `/thinking level` 才沿当前 Conversation 的配置与原请求核对路径提交。

设置页以常用可视化控件编辑提供商和模型参数，高级编辑保留适用的原生继承/覆盖语义。配置写入具备授权、校验、冲突与回执；秘密由可信宿主维护，普通表单接收脱敏状态。「原生参数」用树展示当前对象的公开键和本层值；常规表单已承接的叶子不重复编辑，未承接的子参数仍按原路径可达。宽详情在树旁编辑，窄详情用底部面板。有效输入直接进入同一对象的草稿；不完整的数值或数组保留在该项并阻止保存。分组只组织逐叶操作，不写空对象。宿主管理项只列名称；提供商自身请求头旁列出另设请求头的模型，没有上层请求头时不称为覆盖。模型归属从同一版本的完整身份确认，不按数组位置命名。

实例管理员在「提供商与模型」分别新建提供商、覆盖已有端点、添加模型定义或覆盖目录中的完整模型身份。「模型参数配置」按完整 ID 定位模型；定义和覆盖同 ID 时分组显示。提供商与模型的兼容性设置各自按协议展示，Thinking 映射按 Pi 级别直接编辑提供商请求值，留空恢复继承，单独禁用该级别写入 `null`，采样参数可按模型和 Thinking 级别恢复单键继承。目录是加载快照，既非全部已注册适配器，也非可调用证明；校验、保存、重载和核对原请求均不发送推理。

模型与 Provider 契约属于 pi-ai；交互和公开配置能力参考 pi-coding-agent；持久 Conversation 配置与执行由 Pakka 接到 pi-durable。WebUI 的执行路径沿 Pakka 的持久服务接线。

## 个人模式与设备

宿主在 People 存储域保存 personal/collaboration 模式。已有实例按 collaboration 读取；当前唯一活跃 Person 为全局管理员时，可按版本和稳定请求号启用 personal。仍有其他活跃成员时拒绝切换，保留其原权限和历史作者。切换为 personal 时撤销未兑换的新成员邀请；后续设备连接必须指向本人，以独立登录凭据复用同一 Person。

「设备与访问」显示当前使用模式与本人有效登录，支持单独撤销其他设备。当前设备通过退出登录结束凭据。设备清单只含公开登录标识、有效期和是否当前设备，不包含秘密。模式切换、撤销效果与回执在同一次 People CAS 中提交；版本冲突保留草稿，响应未知按完整原请求查询。

个人模式的各设备拥有一致的人类操作权限，默认模型、Thinking、文件夹与排序沿同一 Person 共享。登录姓名可省略，已有身份沿用原姓名；通知、麦克风、输入草稿和布局仍有各自的设备作用域。Agent 的工具权限、审批与模型策略继续独立核验。

个人模式跳过人类 driver 领取、续期与接管，并在模式切换后使旧 driver 租约失效；原生输入队列、Steering/Follow-up、并发版本检查与原请求恢复继续生效。个人模式不装配人类聊天、提及、reaction、在场或 driver 管理，不发布其能力和事件；仅可核对历史原请求。协作模式恢复独立聊天入口以及原服务保存的聊天记录和聊天置顶。

## Session 预算

Conversation 数量、主要推理尝试和辅助推理尝试是三个独立的 Session 上限。每项为非负安全整数；0 表示该项不限制，不是剩余量为 0。即便没有上限，创建和尝试仍照常计数。它不放宽策略、单个 job、模型、队列、资源容量或权限。预算页根据所选 Session 的实际政策填表：不限制项填 0，既有正数不被新默认替换。保存使用原版本，备注可选，以空字符串表示未填写。时间、操作者、变更、版本和请求号自动保留；修改记录默认显示时间与额度变化，技术身份按需展开。回执未确认时保留原请求并阻止重发。

## Conversation 笔记与置顶

顶部「我的输入」「笔记与置顶」为独立 SVG 图标按钮，有名称、提示与至少 44×44px 命中区。笔记与置顶分两页：宽屏（≥1280px）与阅读区并排，小桌面可移动，手机与搜索、输入记录共享单活动面板。关闭保留该 Conversation 的本地草稿；保存是显式操作。

Note 拥有独立 ID、版本、正文、来源及归属信息；Pin 是可排序、按规范目标去重的关系。保存笔记不向 Agent 发送输入。置顶不复制目标正文；打开原消息或结果时以所读 Session/Conversation 的权限重新解析固定 Entry 与内容位置。笔记摘录是独立正文，已保存来源不可读并不禁止编辑本笔记。并发修改同一笔记保留本机草稿、原版与服务版，删除笔记同时移除它的 Pin。未确认提交只核对该对象原请求。
